# LatentMempool

Efficiently handles real-time transaction processing and smart contract execution via distributed handler service.

LatentMempool is aimed at developers who need a straightforward, dependable solution.

## Installation

1. Clone the repository: `git clone https://github.com/fuad403273/LatentMempool.git`
2. `cd LatentMempool`
3. Install in editable mode: `pip install -e .`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
